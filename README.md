# SPACE (plain HTML/CSS/JS)

1. Copy these files into your existing site's repo (keep your own CNAME file). Open index.html to preview.
2. Edit js/config.js: GitHub username, Formspree ID, giscus values, interests, links, and blog posts.
3. Edit now.html by hand whenever your life changes.
4. Vault: open tools/encrypt.html on your computer, pick your private files and a long password, save vault.enc.json into the site's main folder.
   Only the encrypted file is public. Strength of the password is your only protection, and keep the originals backed up elsewhere.
5. Commit and push with GitHub Desktop.
